## DESKRIPSI MATA KULIAH

Mata kuliah Pengantar Keamanan Siber merupakan mata kuliah keahlian program studi yang memperkenalkan mahasiswa pada prinsip-prinsip dasar, teknik, dan metodologi dalam keamanan siber dan ethical hacking. Mata kuliah ini membangun pemahaman tentang bagaimana mengidentifikasi, menganalisis, dan menanggulangi ancaman keamanan pada sistem informasi, jaringan, dan aplikasi web.

Mahasiswa akan mempelajari konsep dasar keamanan informasi (CIA Triad), teknik pengumpulan informasi (footprinting dan reconnaissance), pemindaian jaringan dan enumerasi, analisis kerentanan, system hacking, malware dan social engineering, network sniffing, serangan Denial of Service dan session hijacking, keamanan web server dan aplikasi web, SQL injection, keamanan jaringan nirkabel, keamanan platform mobile, serta kriptografi dan keamanan cloud computing. Seluruh pembelajaran mengikuti metodologi CEH (Certified Ethical Hacker) v13 dengan penekanan pada aspek etika dan legalitas.

Mata kuliah ini memanfaatkan fondasi dari **Jaringan Komputer (Semester 2)** untuk memahami protokol jaringan, arsitektur TCP/IP, dan analisis lalu lintas jaringan, serta **Sistem Operasi (Semester 3)** untuk memahami arsitektur sistem, manajemen proses, dan file system yang menjadi dasar analisis keamanan. Penguasaan materi ini menjadi fondasi esensial untuk mata kuliah lanjutan yaitu **Digital Forensic for Military Purposes (Semester 5)** yang akan memperdalam teknik investigasi dan analisis bukti digital dalam konteks operasi militer.

## PRASYARAT PENGETAHUAN

### Dari Mata Kuliah Jaringan Komputer (Semester 2)
Mahasiswa diasumsikan telah menguasai:
1. **Model OSI dan TCP/IP**: Layer, protokol, dan fungsi masing-masing
2. **Protokol Jaringan**: HTTP, DNS, SMTP, FTP, ARP, DHCP
3. **Pengalamatan IP**: IPv4, subnetting, routing dasar
4. **Analisis Lalu Lintas Jaringan**: Packet capture dan filtering dasar

### Dari Mata Kuliah Sistem Operasi (Semester 3)
Mahasiswa diasumsikan telah menguasai:
1. **Arsitektur Sistem Operasi**: Windows dan Linux
2. **Manajemen Proses dan Memori**: Proses, thread, virtual memory
3. **Manajemen File System**: Struktur direktori, permission, access control
4. **Command Line Interface**: Penggunaan terminal Linux dan command prompt Windows

## ATURAN PERKULIAHAN

1. **Kehadiran**: Minimal 80% dari total pertemuan untuk dapat mengikuti UAS
2. **Keterlambatan Tugas**: Pengurangan 10% per hari keterlambatan, maksimal 3 hari
3. **Plagiarisme**: Pelanggaran akan dikenai sanksi sesuai peraturan akademik (nilai 0 untuk komponen terkait)
4. **Praktikum**: Wajib hadir dan menyelesaikan tugas praktikum setiap pertemuan
5. **Ujian Susulan**: Hanya diberikan dengan alasan yang sah dan bukti pendukung
6. **Etika Hacking**: Seluruh teknik dan tools hanya boleh digunakan dalam lingkungan lab yang telah disediakan; penggunaan di luar lingkungan lab tanpa izin merupakan pelanggaran serius
7. **Keamanan Lab**: Semua aktivitas hacking dilakukan dalam lingkungan terisolasi (virtual machine) untuk mencegah dampak pada jaringan kampus
8. **Kelengkapan**: Mahasiswa wajib membawa laptop dengan spesifikasi minimum (8GB RAM, 256GB storage) yang telah terinstal VirtualBox dan Kali Linux

## CATATAN PENTING
